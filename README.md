# Content vault

The home of everything that is MADE for an audience: videos, characters, scripts, voices, pitches. A separate vault on purpose (like the MUN vault): it is built up over time and can be shared or handed on without the project, coding and personal notes that live in the main vault (`Codebase and learning`).

**Start here (LLMs):** this README, then `Index.md`, then the hub of the type you are working on.

## Three kinds of content (one folder each)
1. **[[1 AI Generation/AI Generation|AI Generation]]**: made completely by generative models (Higgsfield-type: image, video, voice, lip-sync). Prompt in, finished clip out. No camera, no code-drawn scenes.
2. **[[2 Personal/Personal Content|Personal]]**: content that is the owner's own: pitch, ideas, own voice or face, random experiments. Uses tools from the other two as helpers.
3. **[[3 AI Animation/AI Animation|AI Animation]]**: animated documentaries and animated explainers, including animated characters (a tiger, a bird). The pipeline is built with code plus AI helpers, so it can be repeated and scaled.

Shared material (brand, voice, where files live, research) is in `Shared/`.

## Rules
- Files that are big (videos, audio, images, model files) live OUTSIDE the vault; notes only record the path. See [[Shared/Where files live]].
- No keys, tokens, passwords or account details in any note.
- Label what is tested and what is only a plan. A tool's price or limit carries its source and date.
- This vault is separate from the main vault and the MUN vault. Wikilinks do not cross vaults: use [[Cross-references]] (plain paths and obsidian:// links) when something must point to the main vault, and write the fact here when it is needed here.
- Every finished production gets one row in its type's `Productions` note and one in [[Log]].
